# Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the approved ClickHouse-backed business Dashboard with prominent KPIs, native-SVG charts, recent payments, and a source-ordered taxpayer CDC activity feed.

**Architecture:** Keep analytical access isolated from Oracle by adding a dedicated ClickHouse HTTP boundary, a dashboard repository containing analytical SQL, a service that translates CDC changes into business language, and four read-only FastAPI routes. The browser renders the dashboard with vanilla JavaScript and native SVG, polling every 10 seconds only while Dashboard is active.

**Tech Stack:** Python 3.9.25, FastAPI, httpx, pytest, Jinja2, vanilla JavaScript, native SVG, ClickHouse HTTP API on port 8123.

## Global Constraints

- Dashboard reads ClickHouse only; it never writes Oracle, Kafka, or ClickHouse.
- Operational Payments, Taxpayers, and Stations must remain Oracle-backed and independent of ClickHouse availability.
- Business-day calculations use `Africa/Kampala` explicitly.
- Use the existing ClickHouse objects: `analytics.vw_oracle_payment_analytics`, `analytics.fact_oracle_payment_current`, `analytics.dim_oracle_taxpayer_current`, `analytics.dim_oracle_station_current`, and `analytics.raw_oracle_taxpayer_cdc`.
- The established serving-view column names are `payment_id`, `taxpayer_id`, `taxpayer_name`, `amount`, `payment_status`, `payment_time`, `station_at_payment`, and `current_station`.
- Source ordering must prefer `source_commit_scn`, `source_scn`, `source_ssn`, `kafka_partition`, and `kafka_offset`; `ingested_at` is not authoritative business ordering.
- No React, Vue, Angular, Vite, npm, CDN chart library, or external chart dependency.
- Charts use native SVG generated by `dashboard.js`.
- Preserve the navy/gold application identity and semantic payment colors: successful green, pending amber/gold, reversed red.
- No CDC jargon on the normal Dashboard.
- No raw ClickHouse errors, SQL, credentials, hostnames, or stack traces in browser responses.
- Do not add `TAXPAYER.STATUS` or `STATION.STATUS`.
- Keep Python syntax compatible with Python 3.9; do not introduce `X | None` annotations.

Create `app/clickhouse.py`:

```python
from __future__ import annotations

from typing import Callable

import httpx

from app.config import Settings


class AnalyticsUnavailableError(RuntimeError):
    pass


class AnalyticsOperationError(RuntimeError):
    pass


class ClickHouseDatabase:
    def __init__(self, settings: Settings, client_factory: Callable = httpx.Client):
        self.settings = settings
        self.client_factory = client_factory

    def query(self, sql: str):
        statement = sql.strip().rstrip(";") + "\nFORMAT JSON"
        url = "http://{}:{}/".format(
            self.settings.clickhouse_host,
            self.settings.clickhouse_http_port,
        )
        auth = None
        if self.settings.clickhouse_user:
            auth = (
                self.settings.clickhouse_user,
                self.settings.clickhouse_password or "",
            )

        try:
            with self.client_factory(timeout=5.0) as client:
                response = client.post(
                    url,
                    params={"database": self.settings.clickhouse_database},
                    content=statement,
                    auth=auth,
                )
            response.raise_for_status()
        except httpx.RequestError as exc:
            raise AnalyticsUnavailableError("ClickHouse analytics is unavailable.") from exc
        except httpx.HTTPStatusError as exc:
            raise AnalyticsOperationError("ClickHouse analytics query failed.") from exc

        try:
            payload = response.json()
        except ValueError as exc:
            raise AnalyticsOperationError("ClickHouse returned an invalid response.") from exc

        data = payload.get("data")
        if not isinstance(data, list):
            raise AnalyticsOperationError("ClickHouse response did not contain data rows.")
        return data
```

    def payments_by_station(self):
        return self.db.query("""
        /* payments_by_station */
        SELECT
            if(empty(station_at_payment), 'Unassigned', station_at_payment) AS station_name,
            count() AS payment_count,
            sumIf(amount, payment_status = 'SUCCESSFUL') AS successful_amount
        FROM analytics.vw_oracle_payment_analytics
        GROUP BY station_name
        ORDER BY successful_amount DESC, payment_count DESC, station_name ASC
        """)

    def status_summary(self):
        return self.db.query("""
        /* status_summary */
        SELECT
            payment_status AS status,
            count() AS payment_count,
            sum(amount) AS amount
        FROM analytics.vw_oracle_payment_analytics
        WHERE payment_status IN ('SUCCESSFUL', 'PENDING', 'REVERSED')
        GROUP BY status
        ORDER BY indexOf(['SUCCESSFUL', 'PENDING', 'REVERSED'], status)
        """)

```python
    def recent_taxpayer_events(self, limit=12):
        safe_limit = max(1, min(int(limit), 30))
        return self.db.query("""
        /* recent_taxpayer_events */
        SELECT
            taxpayer_id,
            taxpayer_name,
            taxpayer_type,
            station_id,
            dbz_op,
            source_commit_scn,
            source_scn,
            source_ssn,
            kafka_partition,
            kafka_offset,
            source_commit_time,
            previous_taxpayer_name,
            previous_taxpayer_type,
            previous_station_id
        FROM
        (
            SELECT
                taxpayer_id,
                taxpayer_name,
                taxpayer_type,
                station_id,
                dbz_op,
                source_commit_scn,
                source_scn,
                source_ssn,
                kafka_partition,
                kafka_offset,
                source_commit_time,
                lagInFrame(taxpayer_name, 1, '') OVER w AS previous_taxpayer_name,
                lagInFrame(taxpayer_type, 1, '') OVER w AS previous_taxpayer_type,
                lagInFrame(station_id, 1, '') OVER w AS previous_station_id
            FROM analytics.raw_oracle_taxpayer_cdc
            WHERE is_deleted = 0
            WINDOW w AS (
                PARTITION BY taxpayer_id
                ORDER BY source_commit_scn, source_scn, source_ssn, kafka_partition, kafka_offset
                ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
            )
        )
        ORDER BY source_commit_scn DESC, source_scn DESC, source_ssn DESC,
                 kafka_partition DESC, kafka_offset DESC
        LIMIT {limit}
        """.format(limit=safe_limit))
```

Create `app/services/dashboard.py`:

```python
from datetime import datetime, timezone


class DashboardService:
    def __init__(self, repo):
        self.repo = repo

    def summary(self):
        result = dict(self.repo.summary())
        result["refreshed_at"] = datetime.now(timezone.utc).isoformat()
        return result

    def payments_by_station(self):
        return self.repo.payments_by_station()

    def status_summary(self):
        expected = {"SUCCESSFUL", "PENDING", "REVERSED"}
        by_status = {row["status"]: row for row in self.repo.status_summary()}
        return [
            by_status.get(status, {"status": status, "payment_count": 0, "amount": 0})
            for status in ("SUCCESSFUL", "PENDING", "REVERSED")
        ]

    def recent_activity(self):
        station_names = self.repo.station_name_map()
        activities = []
        for row in self.repo.recent_taxpayer_events():
            activities.append(self._translate_taxpayer_event(row, station_names))
        return {
            "recent_payments": self.repo.recent_payments(),
            "recent_taxpayer_activity": activities,
        }

    @staticmethod
    def _station_label(station_id, station_names):
        if not station_id:
            return "Unassigned"
        return station_names.get(station_id, station_id)

    def _translate_taxpayer_event(self, row, station_names):
        taxpayer_id = row["taxpayer_id"]
        name = row.get("taxpayer_name") or taxpayer_id
        op = (row.get("dbz_op") or "").lower()
        current_station = row.get("station_id") or ""
        previous_station = row.get("previous_station_id") or ""
        previous_name = row.get("previous_taxpayer_name") or ""
        previous_type = row.get("previous_taxpayer_type") or ""
        current_type = row.get("taxpayer_type") or ""

        if op in {"c", "r"} or (not previous_name and not previous_station):
            action = "Taxpayer created"
            detail = name
        elif previous_station != current_station:
            action = "Station changed"
            detail = "{} → {}".format(
                self._station_label(previous_station, station_names),
                self._station_label(current_station, station_names),
            )
        else:
            action = "Taxpayer details updated"
            changes = []
            if previous_name and previous_name != name:
                changes.append("{} → {}".format(previous_name, name))
            if previous_type and previous_type != current_type:
                changes.append("{} → {}".format(previous_type, current_type))
            detail = "; ".join(changes) if changes else name

        return {
            "taxpayer_id": taxpayer_id,
            "taxpayer_name": name,
            "action": action,
            "detail": detail,
            "event_time": row.get("source_commit_time"),
        }
```

Do not include SCN, transaction, Kafka, or ingestion fields in the returned business activity dictionary.

- [ ] **Step 4: Implement Dashboard structure and polling in `dashboard.js`**

Start with:

```javascript
import { api } from "./api.js";

const money = new Intl.NumberFormat("en-UG", {
  style: "currency",
  currency: "UGX",
  maximumFractionDigits: 0,
});

const compact = new Intl.NumberFormat("en", { notation: "compact", maximumFractionDigits: 2 });
const when = value => value ? new Date(value).toLocaleString() : "—";

export class DashboardPage {
  constructor(shell) {
    this.shell = shell;
    this.timer = null;
    this.loading = false;
    this.destroyed = false;
  }

  async render() {
    this.destroyed = false;
    this.shell.content.innerHTML = `
      <div class="dashboard-head">
        <div>
          <p class="eyebrow">Business overview</p>
          <h2>Revenue & Transaction Overview</h2>
          <p>Current analytical view of taxpayer and payment activity.</p>
        </div>
        <div class="dashboard-refresh"><span class="environment-dot"></span><span id="dashboard-refreshed">Loading…</span></div>
      </div>
      <div class="dashboard-kpis" id="dashboard-kpis"></div>
      <div class="dashboard-chart-grid">
        <section class="dashboard-panel"><div class="panel-title"><div><p class="eyebrow">Collection performance</p><h3>Payments by Station</h3></div></div><div id="station-chart" class="chart-stage"></div></section>
        <section class="dashboard-panel"><div class="panel-title"><div><p class="eyebrow">Transaction state</p><h3>Payment Status</h3></div></div><div id="status-chart" class="chart-stage"></div></section>
      </div>
      <div class="dashboard-activity-grid">
        <section class="dashboard-panel"><div class="panel-title"><h3>Recent Payments</h3></div><div id="dashboard-payments" class="loading">Loading recent payments…</div></section>
        <section class="dashboard-panel"><div class="panel-title"><h3>Recent Taxpayer Activity</h3></div><div id="taxpayer-activity" class="loading">Loading activity…</div></section>
      </div>`;
    await this.refresh();
    if (!this.destroyed) this.timer = window.setInterval(() => this.refresh(), 10000);
  }

  destroy() {
    this.destroyed = true;
    if (this.timer) window.clearInterval(this.timer);
    this.timer = null;
  }

  async refresh() {
    if (this.loading || this.destroyed) return;
    this.loading = true;
    try {
      const [summary, stations, statuses, activity] = await Promise.all([
        api("/api/dashboard/summary"),
        api("/api/dashboard/payments-by-station"),
        api("/api/dashboard/status-summary"),
        api("/api/dashboard/recent-activity"),
      ]);
      if (this.destroyed) return;
      this.renderKpis(summary);
      this.renderStationChart(stations);
      this.renderStatusChart(statuses);
      this.renderRecentPayments(activity.recent_payments || []);
      this.renderTaxpayerActivity(activity.recent_taxpayer_activity || []);
      document.querySelector("#dashboard-refreshed").textContent = `Updated ${when(summary.refreshed_at)}`;
    } catch (error) {
      if (!this.destroyed) this.shell.toast(error.message, true);
    } finally {
      this.loading = false;
    }
  }
}
```

The first successful render remains visible if a later polling refresh fails.

renderStationChart(rows) {
  const target = document.querySelector("#station-chart");
  if (!rows.length) { target.innerHTML = `<div class="empty">No station payment data yet.</div>`; return; }
  const max = Math.max(...rows.map(r => Number(r.successful_amount || 0)), 1);
  const width = 720;
  const rowHeight = 46;
  const labelWidth = 150;
  const chartWidth = width - labelWidth - 90;
  const height = rows.length * rowHeight + 20;
  target.innerHTML = `<svg class="dashboard-svg" viewBox="0 0 ${width} ${height}" role="img" aria-label="Successful payment amount by station">
    ${rows.map((r, i) => {
      const value = Number(r.successful_amount || 0);
      const barWidth = Math.max(2, chartWidth * value / max);
      const y = 12 + i * rowHeight;
      return `<g class="station-bar"><text x="0" y="${y + 20}" class="chart-label">${r.station_name || "Unassigned"}</text><rect x="${labelWidth}" y="${y}" width="${barWidth}" height="26" rx="7" class="chart-bar"><title>${r.station_name}: ${money.format(value)} from ${r.payment_count} payments</title></rect><text x="${labelWidth + barWidth + 10}" y="${y + 19}" class="chart-value">${compact.format(value)}</text></g>`;
    }).join("")}
  </svg>`;
}

- [ ] **Step 7: Implement native-SVG donut status chart**

Use SVG circles with `stroke-dasharray` and a legend. Keep the semantic status classes:

```javascript
renderStatusChart(rows) {
  const target = document.querySelector("#status-chart");
  const total = rows.reduce((sum, r) => sum + Number(r.payment_count || 0), 0);
  if (!total) { target.innerHTML = `<div class="empty">No payment status data yet.</div>`; return; }
  const circumference = 2 * Math.PI * 54;
  let offset = 0;
  const circles = rows.map(r => {
    const count = Number(r.payment_count || 0);
    const length = circumference * count / total;
    const dash = `${length} ${circumference - length}`;
    const current = offset;
    offset -= length;
    return `<circle cx="70" cy="70" r="54" class="donut-segment donut-${String(r.status).toLowerCase()}" stroke-dasharray="${dash}" stroke-dashoffset="${current}"><title>${r.status}: ${count} (${Math.round(count * 100 / total)}%)</title></circle>`;
  }).join("");
  target.innerHTML = `<div class="donut-layout"><svg class="donut-svg" viewBox="0 0 140 140" role="img" aria-label="Payment status breakdown"><circle cx="70" cy="70" r="54" class="donut-track"></circle>${circles}<text x="70" y="66" text-anchor="middle" class="donut-total">${total}</text><text x="70" y="84" text-anchor="middle" class="donut-caption">payments</text></svg><div class="donut-legend">${rows.map(r => `<div><span class="legend-dot legend-${String(r.status).toLowerCase()}"></span><span>${r.status}</span><strong>${Number(r.payment_count || 0).toLocaleString()}</strong></div>`).join("")}</div></div>`;
}
```
